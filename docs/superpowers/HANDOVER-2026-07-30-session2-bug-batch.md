## Грабли

1. **jsdom не знает PointerEvent** — Testing Library падает на голый `Event` и МОЛЧА теряет
   `pointerId` и `clientX/clientY`: фильтры указателя сравнивают undefined с undefined, тесты
   вакуумно зелёные. Полифилл живёт в `svgTestGeometry.installSvgGeometry()` — подключай его в
   любом тесте жестов (zyc наступил, 36f-тесты уже жили под ним).
2. **Инференс типов Fastify различается между локальной и свежей (CI) установкой**: локальный
   typecheck зелёный, CI дал `'err' is of type 'unknown'` в `setErrorHandler`. Лечение — явный
   тип параметра (`err: FastifyError`). Единственный красный CI за 16 PR.
3. **Репо требует ветку, догнавшую main** (strict status checks): PR, отставший на один мерж,
   не мержится — `git rebase origin/main` + `--force-with-lease`. Авто-мерж GitHub в репо
   ВЫКЛЮЧЕН: `gh pr merge --auto` молча не цепляется, мержить руками после зелёного CI.
4. **`bd` переписывает `.beads/issues.jsonl` на каждую команду** — при переключении веток файл
   «мешает»; он пассивный: `git checkout -f .beads/issues.jsonl` безопасен (см. SYNC_CONCEPTS).
5. **Демо-стратегия в state ≠ выбор пользователя** — любой новый код, сохраняющий стратегию
   «как сейчас в шапке», повторит wmd. Сохранять только тронутое поле.
6. **Chrome-профиль CDP персистит localStorage между прогонами** — чистить
   `localStorage.clear()` + перезагрузка, иначе черновик заявки копится и репро «не открывается».
