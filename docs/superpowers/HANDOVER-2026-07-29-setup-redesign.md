## Что изменилось для пользователя

Строка позиции сжата до того, что вбивается руками: артикул · Д·Ш·В · количество · **чип-итог
правил** («Verschachtelt · 120», «Stapel bis 3») с числом единиц в стопке · удаление. Из неё ушли
переключатель Ent-/Verschachtelt, селект ориентации, селект оси вил, чип «Stapel N» и раскрывашка.

Правила теперь живут в **панели разбора** справа и там же **объясняются фразами**: «Каждая следующая
садится в предыдущую и добавляет 120 мм. Нижняя — 1900 мм» вместо голого `Δh`. Фразы сверены с
`computeVerticalStack`. Ниже 1280 px панель — выезжающая, `Esc` закрывает, фокус возвращается на чип.

## Решения, которые стоит знать

1. **Компоненты берут перевод через `useT()`/`useLocale()`, а не пропом `tt`.** План прокидывал `tt`
   пропом и одновременно давал тесты, передающие тождественную функцию и ждущие настоящих переводов —
   внутреннее противоречие. `useT()` — доминирующий паттерн репозитория.
2. **Выбранная строка не персистится** — состояние вида, не содержимое плана. Та же граница, что для
   `bayOrder` в `36f`.
3. **Панель рендерится с `key` от выбора.** Без него `saveError` протекал на чужую строку: панель
   стала единственным долгоживущим экземпляром вместо «по панели на строку».
4. **`Esc` при открытой панели и взведённом удалении сначала снимает взведение**, панель закрывается
   вторым нажатием. Два независимых слушателя на документе иначе отменяли два действия за раз.
5. **`aria-modal` с drawer снят.** Настоящей модальности (ловушка фокуса, `inert`) нет — разметка не
   должна обещать больше, чем делает. Долг — `LKWkalk-tn9`.

## Грабли

1. **`npm test -w apps/web` НЕ СУЩЕСТВУЕТ.** Точечно — фильтром пути от корня: `npm test -- SetupScreen`.
2. **Словарь i18n читается тестами из собранного `dist`.** После правки локалей обязателен
   `npm run build -w @shadrin-v/i18n`, иначе тест падает на пустой строке и выглядит как баг компонента.
3. **jsdom не видит раскладку.** Обрезка строки ниже ~700 px прожила через семь ревью именно поэтому;
   поймало её только финальное ревью, а подтвердил настоящий Chrome. **Проверять ширины 375 / 640 /
   768 / 900 / 1280**, а не одну. CDP-скрипты: `Emulation.setDeviceMetricsOverride` + замер
   `scrollWidth` против `clientWidth`.
4. **Сквош-мерж разводит локальную `main` с удалённой.** Если коммитил в `main` до создания ветки,
   после мержа `git pull --ff-only` упадёт. Лечение: убедиться, что локальные коммиты содержательно
   вошли в сквош (`git show origin/main:<файл> | grep`), затем `git reset --hard origin/main`.
5. **Флейк `LKWkalk-w9j`/`bmi` жив и измерен:** по одному падению из девяти прогонов и на ветке, и на
   мерж-базе. Ветка его не привносит. **Не лечится поднятием таймаута** — попытка в этой сессии была
   опровергнута замером: тест идёт 1,03 с при бюджете 5 с.
6. **Тесты, ищущие контролы по СЫРЫМ ключам под `LocaleProvider`, вакуумны.** Доступные имена — это
   переведённые строки; запрос по ключу не совпадёт никогда и тест пройдёт при любом состоянии кода.
   В этой сессии таких нашлось три.
