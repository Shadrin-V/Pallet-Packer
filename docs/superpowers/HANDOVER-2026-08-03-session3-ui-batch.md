## Решения

- **Две фирменные палитры вместо ребрендинга.** Я возражал: продукт с двумя равноправными
  фирменными палитрами не имеет визуальной идентичности, честнее выбрать тёплую единственной.
  Владелец выбрал переключение — зафиксировано в [ADR 025](../adr/025-two-brand-palettes.md) вместе
  с ценой (каждый токен задаётся дважды, контраст меряется дважды).
- **Двухколоночная раскладка отвергнута владельцем** с верным доводом: разрез — чертёж 13,6 м, и
  половина ширины экрана означает половину масштаба; для печатного документа это хуже скролла.
- **Две одинаковые кнопки расчёта** примиряют два прежде конфликтовавших решения: нижнюю убирали в
  `5nb` §6 («под шестью заказами надо домотать»), верхняя оторвана от плана. Верх решает
  досягаемость, низ — соседство с результатом. **Не удаляйте ни одну** — вернётся та жалоба, из-за
  которой её поставили; довод записан комментарием в коде.
- **Чернильный ряд тёплой палитры на ступень темнее G7.** `--faint #9a958c` из артефакта даёт 2.8:1
  при норме 4.5:1. Теперь `#242321` (14.9:1) → `#5a564f` (6.9:1) → `#6e6a63` (5.1:1).
- **`--accent` из G7 не перенесён:** в `forest` такого токена нет, а наборы обязаны совпадать.

## Грабли

- **`border` для пунктирной рамки ломает масштаб двора.** Шапка `WarehouseFloor.tsx` предупреждает:
  любая горизонтальная рамка сужает svg, и мм→px уезжает, **пока `viewBox` всё ещё совпадает** —
  `holdYardScale.test.tsx` такого не ловит. Только `outline`: рисуется вне бокса, места не занимает.
  Замерено в Chrome: двор и разрез в одинаковые 1521 px, дельта масштабов 0.
- **Снимок глобального состояния нельзя читать из `localStorage`, если запись в него в `try/catch`.**
  `applyTheme` пишет атрибут `<html>` безусловно, а `setItem` — под catch. В Safari private mode
  страница перекрашивалась, а `aria-pressed` рассказывал обратное. Источник истины — DOM-атрибут.
- **Гейт, который может ничего не просканировать, хуже отсутствующего.** `noHardcodedHex.test.ts`
  глобил относительно cwd: из `apps/web` находил ноль файлов и **проходил**. Якорить на корень через
  `import.meta.url` и **обязательно** проверять непустоту списка. Тот же класс — открытый `fwl`.
- **`bd close` ломает `gh pr merge --delete-branch`** (повтор из прошлой сессии). На GitHub мерж к
  этому моменту УЖЕ прошёл — падает только локальный `git checkout`. Уточнённое лечение: не затирать
  `.beads/interactions.jsonl`, а `git stash push <файл>` → `git checkout main` → `git pull` →
  `git stash pop`, затем **закоммитить журнал отдельно** (прецедент `89aa813`), иначе он заблокирует
  следующее переключение. `git checkout -- .beads/` не работает, если файл застейджен: сначала
  `git reset`.
- **jsdom не проверяет попадание указателя после синхронного перерендера.** Призрак вставки
  открывался на голом нажатии, двор уезжал под курсором, клик уходил мимо плитки — выделение и
  поворот ломались, а все тесты были зелёные. Ловится только настоящим браузером.
- **Правка тестового хелпера в одном коммите с продакшн-фиксом** — повод отдельно проверить
  самомаскировку: не стал ли зелёным тест, который должен падать. В этот раз обошлось, но проверять
  надо всегда.
- **Поздний фикс не поднимается вверх по иерархии сам.** `border → outline` был исправлен в коде и в
  плане, а спека продолжала предписывать `border` — нашлось только на `/wrap`.

## Живая проверка в браузере (метод сохранён в память `2026-08-03-cdp-browser-verification`)

Playwright/Puppeteer в репо нет и ставить не пришлось: Chrome в `/Applications` + глобальный
`WebSocket` в Node 22 + ~60 строк CDP-драйвера. Проверено то, что jsdom не может:

- масштаб двора и кузова совпадает **точно** при включённой и выключенной кабине;
- нажатие без движения не двигает двор и не съедает выделение;
- перекраска кабины вместе с палитрой; `outline-style: dashed`, `border-width: 0px`;
- шапка на 360/390/414 px в обеих локалях.

**Грабля драйвера:** `Input.dispatchMouseEvent` берёт координаты **вьюпорта** — элемент ниже сгиба
не получит событий вообще. Сначала `scrollIntoView` либо расширить вьюпорт через `Emulation`.
