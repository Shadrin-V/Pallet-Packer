## Что изменилось для пользователя

1. **Заказы в «Настройке» больше не сливаются в один список** — между карточками 32 px вместо 16.
2. **На стопках схемы написано, что за груз** — имя артикула стоит над количеством в виде сверху и
   на складе. Боковой разрез остался без подписей.

## Решения, которые стоит знать

1. **Ширину SVG-текста нельзя мерить `getComputedTextLength`** — его нет в jsdom, юнит-тесты
   разошлись бы с продом. Оценка арифметическая, в чистой функции `stackLabel`.
2. **Плоский коэффициент ширины глифа не годится в обе стороны.** Замер в Chrome: прописные
   0,65 em, строчные 0,50, цифры 0,63, многоточие 0,65. Реальные имена: `Viertelpalette` 0,43,
   `SONDERPALETTE` 0,62. Один коэффициент 0,58 выпускал бы капс за край стопки и одновременно резал
   бы строчное имя на треть раньше нужного — поэтому оценка считает знаки по классам.
3. **Имя пропадает, количество остаётся.** Три случая деградации до одного `×N`: стопка ниже двух
   строк, после обрезки меньше трёх знаков, групповая стопка смешанного типа.
4. **Теста на класс контейнера для отступов нет намеренно** — в jsdom нет раскладки, такой тест
   утверждал бы строку `className`, а не разделение. Проверка — измерением в настоящем Chrome.

## Грабли

1. **Имя артикула теперь есть и на стопках** — общестраничные `getByText(/<имя>/)` в тестах стали
   неоднозначными. Сломался тест легенды в `LadeplanScreen.test.tsx`; лечение — сузить запрос через
   `within(screen.getByRole('region', { name: 'Legende' }))`.
2. **Корневой `npm test` локально шумит на 35 падений `apps/server`** (better-sqlite3 под чужой
   Node). Пока `3c5` не закрыт, гейт приходится читать выборочно — и это ровно тот режим, в котором
   пропускают настоящую регрессию. Перед выводами сверяйся с CI на PR.
3. **Флейк `LKWkalk-bmi` шире своего названия:** таймаут `userEvent` гуляет по разным тестам
   `SetupScreen.test.tsx`, не только по «save button is always present». Мера — прогнать файл
   отдельно; три прогона подряд зелёные.
4. **`bd` переписывает `.beads/issues.jsonl` на каждую команду**, поэтому переключение веток падает
   с «local changes would be overwritten». Файл — пассивный экспорт: безопасно
   `git checkout -f <branch>`, затем `bd export -o .beads/issues.jsonl`. Тот же файл конфликтует при
   ребейзе — разрешать не руками, а повторным экспортом.
5. **`Page.captureScreenshot` с `clip` хочет координаты СТРАНИЦЫ, не вьюпорта** — прибавляй
   `scrollX/scrollY` и ставь `captureBeyondViewport: true`, иначе получишь пустой прямоугольник.
