## Что сделано

1. **`5tg` — счётчик выделения читаем.** Подпись «N стопок выделено» была голым текстом `--brand`
   над рамкой: тонула в штриховке соседнего ряда, а у выделения в первом ряду уезжала за переднюю
   стенку. Новый чистый модуль `selectionBadge.ts` — подложка, переворот внутрь рамки, прижатие к
   кромкам; `CrossSection` только рисует.
2. **`103` — двор не наезжает на доки.** Решение владельца: доки ужаты до `DOCK_DEPTH_RATIO` = 0.6
   минимальной глубины двора, под них отведены боковые поля. Ширины считает одна экспортируемая
   `dockWidths(dockHeight)`. Поля двора стали асимметричными (`padLeft`/`padRight`), вертикальные —
   общий `PAD`. Ряд теряет ~0,82 м вместо ~1,4 м.
3. **`x7e` — печать молчит о неразмещённом.** Убраны показатель в сводке и приписки в легенде.
   **Осознанная отмена `rgv.7`** в части печати; экран и PNG не тронуты.
4. **`7i6` — тумблер показа грузовика.** Один флажок на оба разреза, охват экран + печать + PNG.
   Прячется обвес (`data-truck-chrome`); линейки и рамка кузова остаются. Ключ
   `localStorage` `ladungsplaner.showTruck`.
5. **`6zp`** — общий справочник владельца дописан (ladungsplaner: контейнер, Basic Auth, DNS-зона,
   бэкап, ветка автодеплоя, доступы, smoke). §9 рунбука переписан с «что дописать» на «дописано».

## Грабли

1. **`@shadrin-v/i18n` резолвится в `dist`.** После правки словаря ОБЯЗАТЕЛЕН
   `npm run build -w packages/i18n`, иначе тесты не видят новую строку и падают с «Unable to find
   an accessible element» — выглядит как ошибка вёрстки, а не сборки.
2. **Слабый тест ловится вырожденной заглушкой.** Проверки вида «0 ≤ y» проходили на плашке 0×0,
   то есть на ОТСУТСТВУЮЩЕЙ подложке. Утверждения должны держать РАЗМЕР, а не только края —
   заглушка, возвращающая нули, обязана валить тест.
3. **Печать и PNG получают состояние вида даром**, потому что оба выводят ЖИВЫЕ svg листа. Тест
   пинует именно это свойство: подмена на перерисовку молча развела бы картинку с экраном.
4. **`~/Documents/dev/IT Infrastruktur` в контур проекта НЕ входит** (решение владельца). Агент
   ошибочно перенёс туда справочник владельца — откачено `git reset --hard`. Общий INFRASTRUKTUR.md
   — документ владельца вне git, рабочая копия `~/Downloads/INFRASTRUKTUR.md`.
5. `cp` из `~/Downloads` блокируется классификатором разрешений; резервную копию делать через Write.
